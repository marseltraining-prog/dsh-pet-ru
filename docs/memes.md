# Мемы (表情包)

Всего **27** картинок. Имя в конфиге = имя файла `~/.dsh/dsh-pet/memes/<имя>.png`.
Описание уходит модели: по нему она выбирает картинку к реплике (в чат — первые
`chatImageLimit` штук в порядке записи, в бормотание — случайная).
