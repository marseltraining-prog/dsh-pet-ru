# Подписи меню: что найдено, что заменено, что осталось

Проверялись два бандла, которые грузит DSH: `lib/client.js` (браузерная половина —
оверлей питомца, меню, пузыри, панель задач, диалог) и `lib/index.js` (хостовая
половина — слэш-команды, баланс, голоса). Подписи искались как китайские строковые
литералы в регионах `//#region src/...`; отладочные логи (`console.*`, префикс
`[dsh-pet]`) в перевод не входят — их пользователь не видит.

Итог: **187 / 200** в `lib/client.js`, **25 / 25** в `lib/index.js` и **157 / 166**
в бандле настольного окна `runtime/electron-helper/*`. Всего **369 записей /
391 вхождение**. Полная таблица «было → стало» — в
[translated-strings.md](translated-strings.md).

## 7. Настольное окно (`display: "desktop"`)

При `display: "desktop"` питомец живёт в плавающем окне, которое рисует **отдельный
бандл** `runtime/electron-helper/` — правки в `lib/client.js` на него не влияют.
Поэтому он патчится отдельно, теми же переводами:

| Файл | Что переведено |
| --- | --- |
| `sprite/menu.js` (11) | Показать баланс / Задачи / Побормотать / Чат / Спать / Проснуться / Перезагрузить конфиг / Вернуть на место, а также первый пункт «Открыть приложение / Открыть настройки ИИ / Открыть сайт» |
| `shared-core.js` (136) | те же общие модули, что в `client.js`: дерево «Действия», «Где показывать», «Ещё», ветка «Картинки», задачи с календарём и датами, диалог, голосовой ввод, баланс, очки, уведомления, бормотание |
| `index.html` (2) | `<html lang="ru">` и заголовок окна «dsh-pet — питомец (настольный режим)» (было `zh-CN` и «dsh-pet 桌宠（桌面模式）») |
| `main/tray.js` (2) | пункт лотка «Выход» и подсказка «dsh-pet — питомец» |
| `renderer.js` (4) | сообщения об ошибке конфигурации в окне |
| `sprite.js` (2) | подсказки модификаторов «Cmd + ЛКМ» / «Ctrl + ЛКМ» |

## Что НЕ заменено и почему

| Что | Почему |
| --- | --- |
| `src/client/pet/menu-actions.ts` — `"睡觉"` / `"起来"` / `"余额刷新动作"` и т.п. | Это аргумент `label` только для `console.info/warn` («[dsh-pet] меню…»), в UI не попадает. Замена сломала бы читаемость логов, ничего не дав пользователю. |
| `src/client/pet/card/sleep-machine.ts`, `animation-flow.ts`, `cue-effects.ts`, `pet/animation/animation.ts`, `multi.ts`, `nav-icon.ts`, `app-shortcut.ts` | Отладочные сообщения (`console.*`) и тексты причин для логов. |
| `src/shared/fonts.ts`, `todo/styles.ts`, `chat/styles.ts`, `score-popup.ts`, `client/bubble.ts` — `'幼圆'`, `'Microsoft YaHei'`, `上首软糖体.ttf` | Имена системных шрифтов и файла шрифта: их нельзя переводить, иначе фолбэк шрифтов перестанет работать. |
| Словарь `zh` (`src/client/settings/locales/zh.ts`) и `src/client/chat/locales/zh.ts` | Штатный китайский словарь: он должен остаться китайским, иначе DSH на китайском сломается. Проверка убеждается, что патчи его не задели (ru и zh по-прежнему 220 и 50 ключей). |
| `lib/app.js` (main-процесс Electron + HTML страницы настроек standalone-режима) | Подписей меню питомца там нет: окно и меню строит `runtime/electron-helper/*`, он пропатчен. В `app.js` остаются служебные тексты запуска и отдельная страница standalone-настроек. |
| `sprite/bubble.js`, `sprite/init.js`, `main/ipc.js` — отдельные строки | Это отладочные поля (`lastBubbleTitle`) и диагностика, в интерфейсе не видны. |
| Комментарии в бандле (`/** … */`, `// …`) | Не видны пользователю; трогать их — лишний риск. |

## Как это проверяется автоматически

```bash
./apply.sh --check
# [3] патчи бандлов
#   lib/client.js: проверка — заменено 0, уже было 187, ошибок 0
#   lib/index.js: проверка — заменено 0, уже было 25, ошибок 0
#   runtime/electron-helper/shared-core.js: проверка — заменено 0, уже было 136, ошибок 0
#   runtime/electron-helper/sprite/menu.js: проверка — заменено 0, уже было 11, ошибок 0
#   ... (всего 8 файлов)
#   ПРОВЕРКА ПАТЧЕЙ: ОК — все строки переведены
```

`--check` падает, если хотя бы одна подпись из спецификации не заменена или заменена
дважды, если в конфиге остался иероглиф, если имени анимации нет файла, если ru-словарь
разошёлся по числу ключей с zh или если слияние конфига настоящим кодом плагина
(`readAllConfig`) дало не русский результат.
