# Голос: Gemini TTS «Aoede» + Edge-фолбэк

Русская озвучка питомца: вместо китайских Edge-голосов плагина — **Gemini TTS
`Aoede`** с автоматическим подбором эмоции под каждую фразу. Если ключа нет,
квота исчерпана или сеть недоступна, синтез молча уходит на **Edge
`ru-RU-SvetlanaNeural`** — питомец не замолкает.

```
/voice/speak
  ├─ voiceName без "gemini:"  → Edge, как раньше
  └─ gemini:*                 → lib/voice-gemini.js
       ├─ config: voiceStyle / voiceFallback (кэш по mtime)
       ├─ keys: gemini.keys → gemini.key → env GEMINI_API_KEY
       ├─ POST .../gemini-2.5-flash-preview-tts:generateContent (таймаут 15 с)
       ├─ inlineData PCM → WAV (24 кГц, моно, 16 бит)
       ├─ ffmpeg → mp3 64k → <target>.part → rename
       └─ 429/403 → следующий ключ; сеть/таймаут/все ключи → Edge
```

Провайдер выбирается **по префиксу** `voiceName`: клиент отправляет в
`/voice/speak` ровно то, что лежит в конфиге. Поэтому достаточно
`"voiceName": "gemini:Aoede"`, а `"voiceProvider": "gemini"` — декларативное
поле, код его не читает. Чтобы вернуться на Edge, смените `voiceName`.

---

## 1. Установка

```bash
cd project
./patches/voice/apply-gemini-voice.sh --dry-run   # план, ничего не пишет
./patches/voice/apply-gemini-voice.sh             # патч плагина
```

Скрипт делает preflight → бэкапы `<файл>.bak.<TS>` → патч → `node --check` →
`verify-gemini-voice.cjs` → `tests/dispatch-check.mjs` (реальный бандл, мок
сети/Edge) → манифест. Если проверка после патча падает — автоматический откат.
Повторный запуск — no-op.

Пути переопределяются `--plugin DIR --config FILE` или `DSH_PET_DIR` /
`DSH_PET_CONFIG`. По умолчанию:
`~/.dsh/profiles/desktop/node_modules/dsh-pet` и
`~/.dsh/dsh-pet/main-config.jsonc`.

**После применения нужен перезапуск DSH**: хост читает `lib/index.js` при
старте, а список голосов UI — из `/voice/voices`.

Откат:

```bash
./patches/voice/rollback-gemini-voice.sh
```

## 2. Ключи

Ключи **не входят в репозиторий** и не читаются конфигом. Формат
`~/.dsh/dsh-pet/gemini.keys` — по одному ключу на строку, `#`-комментарии и
пустые строки игнорируются, кавычки по краям снимаются, BOM отбрасывается:

```text
# аккаунт 1
<ключ-аккаунта-1>

# аккаунт 2
<ключ-аккаунта-2>
```

Совместимость: если `gemini.keys` нет — читается старый `gemini.key` (одна
строка); если нет ни одного файла — `GEMINI_API_KEY` из окружения. Файл
перечитывается при каждом синтезе с кэшем по `mtime+size`, поэтому новый ключ
подхватывается **без рестарта**.

Права:

```bash
chmod 600 ~/.dsh/dsh-pet/gemini.keys
```

`.gitignore` проекта исключает `*.key`, `keys*` и `voice-cache/`.

## 3. Квоты и ротация

* Free Tier Gemini TTS — **10 запросов в день на ключ** (на модель); при
  исчерпании приходит `429 RESOURCE_EXHAUSTED`.
* При `429`/`403` ключ помечается исчерпанным **в памяти процесса** до времени
  из `RetryInfo`/`Retry-After`; если время не названо — на 1 час. На диск
  состояние не пишется.
* Когда ключи кончились — синтез уходит на Edge-фолбэк, ошибки пользователю не
  показываются.
* Кэш: ключ = `source + voice|style + rate + text`. Смена стиля не отдаёт старое
  аудио. Если `ffmpeg` не найден, провайдер пишет `.wav` и маршрут выставляет
  `audio/wav`.

Практический вывод: для ежедневного использования одного ключа мало —
держите 2–3 и держите Edge-фолбэк включённым (он включён по умолчанию).

## 4. Эмоции

`pickStyle(text)` проверяет правила по порядку, первое совпадение выигрывает
(поэтому «Не хочу! Фу!» — обида, а не восторг из-за «!»).

| # | Стиль | Когда | Как звучит |
| --- | --- | --- | --- |
| 1 | `sleepy` | спать, сплю, сон, устал, зева, дремл, выспал, «пять минут» | медленно, вяло, тихо, с зевотой |
| 2 | `pouty` | не хочу, не буду, фу, обид, дурак, надоел, бесит | цундэрэ: резко, капризно |
| 3 | `sad` | груст, плак, жалко, одинок, скучно, тоск | тихо, печально, с дрожью |
| 4 | `whisper` | шёпот, тихо, секрет, «по секрету», никому | шёпотом, близко к микрофону |
| 5 | `excited` | `!`, ура, вау, класс, супер, ого, победа | громко, радостно, с визгом |
| 6 | `teasing` | дразн, хитр, ну-ну, кокет, «может быть» | лукаво, тянет гласные |
| 7 | `cute` | печень, ням, вкус, мил, обним, кит, люб, пельмен | высокий голос, улыбка |
| 8 | `warm` | всё остальное | спокойно, тепло, мягко |

Переопределить авто-выбор можно полем `voiceStyle` (`"auto"` — по умолчанию,
иначе один из 8 стилей).

## 5. Конфигурация

```jsonc
"voiceEnabled": true,
"voiceName": "gemini:Aoede",
"voiceProvider": "gemini",       // декларативно
"voiceStyle": "auto",            // auto | sleepy | pouty | sad | whisper | excited | teasing | cute | warm
"voiceFallback": "ru-RU-SvetlanaNeural",
"voiceVolume": 1,
"voiceWhisperEnabled": true,     // озвучивать «бормотание»
"voiceTodoEnabled": false,
"voiceNotifyEnabled": false
```

Без патча `voiceName: "gemini:Aoede"` не пройдёт валидацию (`isKnownVoice`) —
сначала ставьте патч, потом конфиг. `DEFAULT_VOICE` плагина не меняется
(`zh-CN-XiaoyiNeural`).

## 6. Проверки

```bash
./patches/voice/run-tests.sh          # все офлайн-тесты
node patches/voice/verify-gemini-voice.cjs --plugin <dsh-pet> --config <jsonc>
node --experimental-vm-modules patches/voice/tests/dispatch-check.mjs --plugin <dsh-pet>
```

Тесты не ходят в сеть: сеть и Edge замоканы, проверяются выбор провайдера по
префиксу, выбор стиля, ротация ключей, парсинг ошибок, PCM→WAV, фолбэк.
Живой запрос — отдельный флаг `--live` у `tests/live-check.mjs` (тратит квоту).

## 7. Ограничения

* Free Tier: 10 запросов/день на ключ; при нескольких ключах — ротация, но
  суммарная квота всё равно невелика.
* Голос звучит как аниме-девочка: это задумано, но на длинных фразах
  интонация может «плыть» — поэтому фразы питомца короткие (до 20 слов).
* Gemini отдаёт PCM; без `ffmpeg` файл остаётся `.wav` (работает, но тяжелее).
* Ключи — только локально; не коммитьте `gemini.keys` и не вставляйте его в
  issues/скриншоты.
