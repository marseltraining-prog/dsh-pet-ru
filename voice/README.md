# voice — куда положить ключ Gemini

В этом каталоге **нет и не должно быть ключей**. Здесь только инструкция.

## 1. Файл с ключами

```bash
mkdir -p ~/.dsh/dsh-pet
printf '%s\n' 'ВАШ_КЛЮЧ' > ~/.dsh/dsh-pet/gemini.keys
chmod 600 ~/.dsh/dsh-pet/gemini.keys
```

Несколько ключей — по одному на строку; `#`-комментарии и пустые строки
игнорируются:

```text
# аккаунт 1
<ключ-аккаунта-1>

# аккаунт 2
<ключ-аккаунта-2>
```

Файл читается провайдером при каждом синтезе (кэш по `mtime+size`), поэтому
новый ключ подхватывается без перезапуска DSH.

## 2. Порядок поиска

1. `~/.dsh/dsh-pet/gemini.keys` — список;
2. `~/.dsh/dsh-pet/gemini.key` — старая версия, одна строка;
3. переменная окружения `GEMINI_API_KEY`.

## 3. Что будет без ключа

Ничего не сломается: каждая фраза синтезируется Edge-голосом
`ru-RU-SvetlanaNeural` (`voiceFallback` в конфиге). Gemini включается только
когда ключ есть и не исчерпан.

## 4. Квота

Free Tier Gemini TTS — **10 запросов в день на ключ**. При `429` ключ
ротируется; когда ключи кончились — Edge-фолбэк. Для ежедневного использования
держите 2–3 ключа.

## 5. Безопасность

* не коммитьте `gemini.keys`, `gemini.key`, `*.key` — они в `.gitignore`;
* не вставляйте ключ в скриншоты, issues и логи;
* если ключ попал в git-историю — отзовите его в Google AI Studio.

Подробности: [`../docs/voice.md`](../docs/voice.md).
